# Agent guidance

Follow the repository guidance in `CLAUDE.md`, including its evidence,
verification, documentation, and Git conventions.

Do not weaken the digest-pinning rule, the reproducer requirement for
findings, or the honest reporting of unexplained differences merely to make a
comparison look complete.

Never add `Co-Authored-By`, AI, assistant, or tool-attribution trailers to
commits. Tool attribution belongs in tool logs, not Git history.
