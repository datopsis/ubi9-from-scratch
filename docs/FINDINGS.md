# Findings

What the dissection showed.

> [!IMPORTANT]
> Empty by design. A finding is added here only after it has been reproduced
> from a command recorded in `docs/METHOD.md`, and it carries that command,
> the image digest, and the tool version alongside it.

Each entry states which of the following it is:

- **Observed** — read directly from the image.
- **Inferred** — derived from RPM metadata or Red Hat's published build
  inputs, and labelled with what the inference rests on.
- **Unexplained** — a real difference or artefact with no established cause.

Unexplained entries are results, not failures. They are not to be removed
because they are inconvenient.
